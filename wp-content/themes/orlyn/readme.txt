== Description ==

Orlyn is a modern, multi-purpose Full Site Editing (FSE) block theme for WooCommerce-powered stores. It ships a ready-made homepage, dedicated shop, product, cart, and checkout templates, a filterable product sidebar, and a sticky/transparent header with mobile pull-out navigation. Self-hosted Google Fonts (Lexend, Playfair Display, Public Sans) and RTL language support included.

Build your store visually in the Site Editor: every template, template part, and pattern is made of core blocks, so you can restyle colors, typography, and layout globally without writing code. The theme is lightweight, accessible, and ready for WooCommerce out of the box.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
