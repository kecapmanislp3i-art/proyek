== Description ==

Prespa Commerce serves as a child theme of Prespa, inheriting all the features of Prespa. The theme is tailored for e-commerce websites and integrates flawlessly with WooCommerce. It is suitable for blogs, portfolio websites, business websites, fashion stores, accessory shops, boutiques and other types of online shops. Theme demo: https://prespa-commerce-demo.nasiothemes.com/
